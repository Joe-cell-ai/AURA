# Development roadmap

1. Foundation: Android shell, Compose UI, navigation, CI, licensing and tests.
2. AI conversation: provider adapters, local runtime, cloud adapters and router.
3. Voice: push-to-talk, STT, TTS, interruption and wake-word feasibility.
4. Memory: conversation history, user-approved long-term preferences and controls.
5. Android actions: app launch, reminders and permission-gated integrations.
6. Smart home: Home Assistant and supported Wi-Fi/Bluetooth device integrations.
7. Automation: schedules, triggers, conditions, action logs and cancellation.
8. Multimodal: image input, document parsing and web search.
9. Extensions: SDK, manifest, permission model, signing and catalogue.
10. Release: security, performance, battery, compatibility and APK validation.

Each batch must have automated tests, a successful Android build, documented limitations and a testable artifact before it is considered complete.
